  # 🚀 Ripleytia Kick Downloader Pro
  **Kick.com'dan videoları, klipleri ve yayın tekrarlarını kalite kaybı olmadan, en hızlı şekilde indirebilmeniz için tasarlanmış profesyonel bir Windows masaüstü uygulaması.**

## 🌟 Proje Hakkında

`KickDownloaderToolV1`, popüler yayın platformu Kick.com üzerindeki içerikleri cihazınıza kalıcı olarak kaydetmenizi sağlayan güçlü bir araçtır. Kick'in sürekli değişen API altyapısına karşı özel bypass (m3u8 parsing) algoritmaları ile donatılmıştır, bu sayede "404 Not Found" hatalarına takılmadan orijinal kalitede indirme yapabilirsiniz. 

Tamamen neon mor ve siyahın uyumunu taşıyan **Ripleytia** özel temasına sahip şık, basit ve kullanıcı dostu bir arayüz ile gelir.

## ✨ Temel Özellikler

- **🎬 Klip İndirme:** Kick kliplerini URL'den anında tespit edip istediğiniz çözünürlükte indirin.
- **📼 Yayın Tekrarı (VOD) Desteği:** Uzun saatler süren geçmiş yayın tekrarlarını eksiksiz şekilde kaydedin.
- **📦 Toplu İndirme:** Alt alta eklediğiniz birden fazla Kick linkini otomatik olarak sırayla indirerek zaman kazanın.
- **⚙️ Kalite Seçenekleri:** "En İyi Kalite", "1080p", "720p" veya özel çözünürlük/FPS seçenekleri arasından dilediğinizi seçin.
- **🛡️ API Bypass:** Kick API engellemelerini aşmak için doğrudan akış üzerinden indirme teknolojisi.
- **🎨 Özelleştirilmiş Tema:** Göz yormayan karanlık mod (Dark Mode) ve mor neon Ripleytia arayüz tasarımı.

## 🚀 Kurulum

Herhangi bir ekstra yazılım (Python, Node vb.) kurmanıza gerek yoktur. Tamamen tek başına çalışabilen (standalone) bir dosyadır.

1. Sağ taraftaki **[Releases](https://github.com/ripleytia/KickDownloaderToolV1/releases)** sekmesine gidin.
2. En güncel sürümdeki `Ripleytia_Kick_Downloader.exe` (veya `.zip`) dosyasını bilgisayarınıza indirin.
3. İndirdiğiniz `.exe` dosyasına çift tıklayarak uygulamayı hemen kullanmaya başlayın!

## 💡 Kullanım

1. Uygulamayı çalıştırın.
2. İndirmek istediğiniz içeriğin türüne göre üstteki sekmelerden **(Klip / Yayın Tekrarı / Toplu)** birini seçin.
3. Kick.com üzerinden kopyaladığınız URL'yi arama çubuğuna yapıştırın.
4. **"Kaliteleri Getir"** butonuna tıklayın ve listeden dilediğiniz video kalitesini seçin.
5. Alt kısımdan kayıt yerini belirledikten sonra **"İndir"** butonuna tıklayın.
